## 2024-05-05 - Dynamic Content Accessibility
**Learning:** In vanilla JavaScript SPAs where content updates dynamically (like a quiz UI), screen readers are unaware of the DOM changes.
**Action:** Always add `aria-live="polite"` and `aria-atomic="true"` to the container element of dynamic content so that screen readers can announce the updates gracefully without requiring a page reload.
## 2024-05-18 - Replaced native alert() with inline feedback for clipboard operations
**Learning:** Native `alert()` calls for non-critical notifications (like confirming text was copied to the clipboard) interrupt the user's flow and can feel abrupt or annoying. Providing inline feedback directly on the triggered element (e.g. changing a button's text to "✅ 복사 완료!" temporarily) creates a much smoother and more delightful micro-interaction. However, the `alert()` fallback must be preserved for environments where `navigator.clipboard` is completely unavailable.
**Action:** When implementing 'copy to clipboard' fallbacks, default to inline UI state changes on the trigger element (using safe DOM APIs like `document.createElement`) and gracefully degrade to native alerts only when necessary (e.g., in `catch` blocks or unsupported contexts). Always clone the button's original nodes before altering it so complex structures (like text with SVGs) can be reliably restored.
